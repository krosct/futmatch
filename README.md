# ⚽ FutMatch
### Transforme o racha de fim de semana na Champions League dos seus amigos.

**Chega de discussão de par-ou-ímpar, papel amassado e briga por placar.**  
O **FutMatch** é o organizador definitivo de peladas que equilibra os times, comanda as rodadas, narra com efeitos sonoros hilários e grava cada gol para você saber quem realmente é o craque (ou o bagre) do grupo.

---

</div>

## ✨ Por que você nunca mais vai jogar sem ele:

- 🧠 **Sorteio Balanceado por IA:** Monte times justos em 1 segundo cruzando notas técnicas, goleiros fixos e posições. Adeus "panela"!
- ⏱️ **Mesa de Som & Efeitos Épicos:** Apito inicial, vinheta do Galvão, narrador clássico, aplausos e memes instantâneos ao toque de um botão.
- 📱 **Instala Direto no Celular (PWA):** Leve, sem precisar de loja, funciona em tela cheia direto do seu navegador Android ou iPhone.
- 📊 **Estatísticas & Tabela ao Vivo:** Saldo de gols, artilharia, ranking de vitórias e histórico completo salvo automaticamente.
- 🔒 **Controle & Compartilhamento:** Compartilhe o link da pelada para todos acompanharem o placar em tempo real na arquibancada.

## 🚀 Como Rodar em 30 Segundos

```bash
# 1. Clone o projeto
git clone https://github.com/krosct/futmatch.git
cd futmatch

# 2. Crie e ative o ambiente
python3 -m venv .venv
source .venv/bin/activate

# 3. Instale e jogue!
pip install -r requirements.txt
uvicorn app.main:app --reload --port 4796
```

> Abra no celular ou navegador em `http://localhost:4796`, clique em **Instalar App** e viva o futebol como nunca antes. 🏆
